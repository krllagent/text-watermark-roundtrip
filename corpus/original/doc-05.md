# How to Photograph a Compact Ceramic Collection

You do not need a studio to compile a useful record of a small ceramic collection. A table, two lamps, white paper, and a phone are enough for a meticulous inventory. The goal is consistency. Each object should appear at a consistent scale, under similar light, with a factual label. That uncomplicated setup helps a later viewer compare shape, color, and condition without guessing which difference came from the camera.

Before the session, dust each object with an appropriate soft brush and record any loose fragment on the inventory sheet. Photograph existing damage before cleaning, and stop if a surface flakes. Fragile pieces belong on padded fabric until their turn at the table.

Begin by choosing a table that does not move when touched. Place it beside a window, but avoid direct sun because the light can shift quickly. Use a large sheet of neutral paper as the background. Curve the paper upward against a box so there is no sharp horizontal line behind the object. A neutral white or gray surface usually produces a sharply visible edge around glazed pieces.

Next, select two lamps with matching bulb colors. Put one lamp on each side roughly level with the object. If reflections look intense, move the lamps farther away and place thin paper in front of them. Do not let the paper touch a hot bulb. This method should lower glare and retain enough detail to show chips, scratches, and painted marks.

Create an item code before you start shooting. A code such as `CER-014` is better than a descriptive filename that may alter over time. Write the code on a little card and include the card in the first frame. Then take it away for the remaining views. Keep a separate note that connects the code with the maker, size, location, and any uncertain designation from an old label.

For each piece, photograph five fixed views: front, back, left side, right side, and base. Add one detail photograph for every material flaw. A detail frame records a flaw without replacing the full object view. Try to retain the camera position while rotating the ceramic. A stack of books can assist with height, although a small tripod will improve repeatability.

Check focus before moving to the next piece. Zoom into the maker's mark and verify that each letter is readable. If the lettering is illegible, attempt another frame with the light at a different angle. A quick review on the phone may miss motion blur, so inspect the files on a larger screen before you conclude the session. This second review can prevent a difficult reshoot weeks later.

Use a folder structure that leaves the archive readily inspectable. One folder holds the original images, one holds cropped copies, and one contains the inventory sheet. Never delete an original because a crop looks better. A future inquiry may require a section that was outside the crop. If file size must shrink, lower the dimensions of a copy and keep the source unchanged.

Name files with the item code and view, such as `CER-014_base_01.jpg`. Avoid private names or real email addresses in metadata. For a fictional sharing test, ceramics@example.com is sufficient. A private note may also carry #CeramicInventory, but public tags are not required. The main aim is a durable archive, rather than a fast social post.

Conclude by opening a random sample of files and matching them against the objects. Verify codes, count views, and identify missing details. Write any problem in the inventory sheet while the setup is still available. A consistent photograph cannot establish value, age, or authenticity. It can display visible condition clearly and give an expert better evidence for a later assessment. That limited outcome is useful on its own.
