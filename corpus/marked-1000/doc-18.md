# Operating Guide for the Sample Freezer

This guide describes a fictional training freezer in an invented teaching lab. It is not a real laboratory protocol. All names, labels, and contacts are synthetic. The main goal is cold storage for labeled practice samples that remain easy to locate and separate from food.

Before opening the freezer, check the wall panel. The temperature should appear inside the marked practice range. If the screen is blank or shows an alert, do not begin storage. Record the time and tell the fictional supervisor at freezer@example.com. The status page is https://example.test/training-freezer.

Prepare the container at the bench. Write the class code, date, and box number in plain letters. Use the same code on the lid and side. A clear label helps staff determine which box it is when frost covers one surface. Do not use a real person's name, email address, or other private information.

To add a box, select an empty position on the paper map. Open the door, place the box, and complete the move within one minute. A quick move can reduce warming. It is still more important to avoid dropping a box, so ask another person to assist with a large container.

Mark the occupied position on the map. The map should show rack, shelf, and slot. A simple entry such as `R2-S1-04` is sufficient. If the slot on the map already has a mark, shut the door and verify the physical position before moving anything.

To retrieve a box, choose the map entry first. Do not search every shelf with the door open. Take out only the selected box and check both labels. Two boxes can appear indistinguishable, so the code must provide the final answer. If the code is unclear, return the box and ask for a second review.

The weekly review has four steps. First, inspect the screen and door seal. Second, detect ice that blocks a rack. Third, compare five map entries with actual boxes. Fourth, discard expired practice samples. A careful operator will record both an accurate entry and any problem found.

Use the tag “hold” when a box may be in the wrong slot. The literal label is protected in this document. A held box stays in place until the supervisor can verify it. Do not delete its map entry. Keeping the entry preserves the basis for the review and lowers the chance of a second move.

If the temperature alert appears, retain the displayed value and time. Leave the door closed. The alert may have a simple cause, such as a loose plug, or a more significant issue. This guide does not ask a trainee to decide. The supervisor will choose whether to move boxes to the backup freezer.

A power loss creates a different situation. Do not repeatedly open the door to check the contents. Place a paper notice on the handle and call the fictional number on the wall. A synthetic team update may mention @training_lab and #freezer-hold. The replacement materials cap is $300, and the drill target is 95% correct map matches.

After each month, the supervisor will compare map accuracy, alert records, and discarded boxes. The expected result is a current map and no unexplained container. A small mismatch should still be recorded. Frequent mismatches may require a new shelf label or a different training method.

During a drill, the supervisor can place one empty practice box in the wrong slot. A trainee should find it by checking the map, write a clear hold note, and leave the door open only for the required move. The empty box prevents damage if the drill is handled incorrectly.

The guide has a narrow scope. It can guide staff as they use one invented storage system and produce a shared record. It cannot detect sample quality or replace specialized safety training. Anyone who is uncertain should stop and ask a question before changing the freezer.
